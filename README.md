# 도시 날씨 웹앱

## 파일 구분

| 구분 | 파일 | 역할 |
| --- | --- | --- |
| 프론트엔드 | `index.html` | 도시 입력창, 버튼, 날씨 결과 화면 |
| 프론트엔드 | `style.css` | 화면 디자인과 모바일 레이아웃 |
| 프론트엔드 | `script.js` | 백엔드 요청, 로딩·오류·결과 표시 |
| 백엔드 | `server.js` | 화면 제공, 외부 API 호출, 결과 반환 |

HTML·CSS·JavaScript와 Node.js 기본 모듈만 사용합니다. 프레임워크, 데이터베이스, npm 패키지 설치는 필요 없습니다.

## 실행 순서

1. PowerShell에서 `node --version`으로 Node.js 설치를 확인합니다. Node.js 18 이상이 필요하며 이 컴퓨터에는 이미 설치되어 있습니다. 다른 컴퓨터에서는 [Node.js](https://nodejs.org/)의 LTS 버전을 설치하세요.
2. 저장소를 다운로드하거나 Git으로 복제한 뒤 날씨 앱 폴더로 이동합니다.

   ```powershell
   git clone https://github.com/zee-0217/my-weather-app.git
   cd my-weather-app
   ```

3. 백엔드를 실행합니다.

   ```powershell
   node server.js
   ```

4. 브라우저에서 `http://localhost:3001`을 엽니다. HTML 파일을 직접 더블클릭하지 않고 서버 주소로 접속하세요.
5. `서울`, `부산`, `London` 등의 도시를 입력하고 **날씨 확인** 버튼을 누릅니다. Enter 키로도 조회할 수 있습니다.
6. 사용하는 동안 서버 창을 열어 두고, 종료할 때는 `Ctrl+C`를 누릅니다. 다음에는 2~4단계를 반복합니다.

이미 다운로드한 폴더가 있다면 복제 명령을 다시 실행하지 않고 해당 폴더에서 `node server.js`를 실행하세요.
원래 작업 폴더에서는 `C:\Users\Jeehee\OneDrive\Desktop\project_261013\weather-app`으로 이동하면 됩니다.

3001번 포트를 이미 사용 중이면 서버를 종료하거나 다음과 같이 실행하세요.

```powershell
$env:PORT = "3002"
node server.js
```

이 경우 접속 주소는 `http://localhost:3002`입니다.

## 동작 방식

브라우저 `script.js` → 우리 서버 `GET /api/weather?city=서울` → 도시 검색 API → 날씨 API → 화면 표시

백엔드가 도시 이름을 좌표로 바꾸고 해당 좌표의 현재 기온, 체감온도, 습도, 풍속, 날씨 상태를 가져옵니다.
외부 API 주소는 서버에 고정되어 있습니다. API Key와 `.env` 설정은 필요 없습니다.
인터넷 연결이 필요하며, 외부 API 오류나 도시 검색 실패는 화면에 안내됩니다.

## 데이터 출처

- [Open-Meteo 날씨 API](https://open-meteo.com/en/docs)
- [Open-Meteo 도시 검색 API](https://open-meteo.com/en/docs/geocoding-api) / GeoNames
- [무료 API 이용 조건](https://open-meteo.com/en/pricing): 무료 공개 API는 비상업적 사용에 제공되며 호출량 제한이 있습니다.

현재 날씨는 기상 모델 기반 데이터입니다. 기준 시각은 해당 도시 시간대로 표시합니다.
현재 강수량은 API가 제공하는 직전 집계 구간의 누적값이며, 화면에 집계 시간을 표시합니다.
내일 예보에는 날씨 상태, 최고·최저 기온, 하루 예상 강수량과 하루 중 최대 강수 확률을 표시합니다.
추천 옷차림은 프론트엔드 `script.js`에서 간단한 기온 구간 규칙으로 계산합니다.
도시 검색 후 해당 도시의 위키백과 대표 사진을 배경에 표시합니다. 도시 문서에서 사진을 찾지 못하면 좌표 주변 10km 이내의 명소 사진을 조회합니다. 사진이 없거나 로딩에 실패하면 기본 배경색을 유지합니다.
사진 출처와 저작자·이용 조건은 화면 하단의 Wikimedia Commons 링크에서 확인할 수 있습니다.
현재는 체감온도(없으면 기온), 내일은 최고·최저 기온을 기준으로 안내하며 비·눈·바람과 일교차에 따라 준비물 팁을 추가합니다.
개인의 추위 민감도와 활동량에 맞춰 조절할 수 있는 참고용 추천입니다.
내일 날짜는 검색한 도시의 시간대 기준입니다. 강수량은 비·눈 등을 포함한 수량(mm)이며 예보는 변경될 수 있습니다.
`New York`, `Los Angeles` 등 띄어쓰기 있는 이름은 전체를 검색합니다. 중복 공백을 정리하고 전체 이름이 같은 도시를 우선하며, 같은 이름이면 인구가 많은 도시를 선택합니다. 결과의 지역명을 확인하세요. 국가를 구분하려면 `Paris, France`처럼 입력할 수 있습니다.
한국어 검색이 되지 않으면 `Seoul`, `Busan` 같은 영문 이름을 사용해 보세요.

## 변경 사항 검증

`node --test server.test.js`로 전체 도시 이름 검색, 주변 명소 사진 조회, 사진 서비스 장애 시 날씨 유지 동작을 검증할 수 있습니다. 테스트는 외부 API를 호출하지 않습니다.
